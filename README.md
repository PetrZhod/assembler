# Ассемблер и интерпретатор УВМ

Практическая работа по конфигурационному управлению. Вариант 10.
На этапе 1 реализованы алгебраический синтаксис ассемблера и перевод
исходной программы во внутреннее представление.

## Синтаксис

Одна команда записывается в отдельной строке. После `#` начинается комментарий.

| Команда | Синтаксис | Поля |
|---|---|---|
| Загрузка константы | `accumulator = B` | `A=0`, `B=0..1023` |
| Чтение памяти | `accumulator = memory[accumulator]` | `A=7` |
| Запись в память | `memory[B] = accumulator` | `A=1`, `B=0..16777215` |
| Квадратный корень | `accumulator = sqrt(accumulator)` | `A=5` |

Программа с тестами спецификации находится в `examples/variant10.asm`.

## Запуск

Требуется Python 3.10 или новее:

```sh
python3 src/main.py examples/variant10.asm build/program.bin --test
```

В режиме тестирования печатаются поля и значения внутреннего представления.
На этапе 1 двоичное кодирование ещё не выполняется.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Репозиторий содержит `src`, `tests`, `.gitignore`, README и сценарии запуска.
Служебные файлы Python, настройки редакторов и артефакты сборки игнорируются.
